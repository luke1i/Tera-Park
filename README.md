# Tera Park

Tera Park is a small 2D platformer made in Godot 4. Move across platforms, dodge the spikes, and collect the coins on the way to the green goal. Touching a spike sends you back to the start.

## Controls

- **A / D** or **Left / Right arrows**: move
- **Space**, **W**, or **Up arrow**: jump

## Play in the browser

Demo: https://urlocalcanadian.itch.io/tera-park

## Run it locally

1. Install Godot (https://godotengine.org/download) 
2. Clone/download this repo
3. Open Godot, click import, and select the project.godot file in this repo
4. Press **F5** to play.
